# Princípios: legalidade, anterioridade e outros

> **Tempo:** 40 minutos · **Pré-requisito:** "Conceito de crime"

## O texto

> **CP, art. 1º.** Não há crime sem lei anterior que o defina. Não há pena sem prévia cominação legal.

(O mesmo está na CF, art. 5º, XXXIX.)

## O que esse artigo exige

| Princípio | Significado |
|---|---|
| **Legalidade (reserva legal)** | Só **lei** (em sentido estrito, feita pelo Legislativo federal) pode criar crimes e penas. Não pode: medida provisória, decreto, resolução, costume |
| **Anterioridade** | A lei tem de existir **antes** do fato |
| **Taxatividade** | A lei deve ser **clara e precisa** ("é crime fazer coisas ruins" seria inválido) |
| **Proibição da analogia *in malam partem*** | Não se pode usar analogia para **prejudicar** o réu (só para beneficiar) |

**Macete:** a lei penal deve ser **escrita, estrita, certa e prévia**.

## Outros princípios do Direito Penal

| Princípio | Significado |
|---|---|
| **Intervenção mínima** | O Direito Penal é a **última opção** (*ultima ratio*); só atua quando outros ramos não bastam |
| **Fragmentariedade** | Protege só os bens jurídicos **mais importantes** contra os ataques **mais graves** |
| **Subsidiariedade** | Só atua se os outros meios de controle falharem |
| **Lesividade (ofensividade)** | Só há crime se houver lesão ou perigo de lesão a bem jurídico **de outra pessoa**; não se pune quem só faz mal a si mesmo (autolesão) nem pensamentos |
| **Insignificância** | Lesões mínimas não são crime (aula própria) |
| **Culpabilidade** | Não há pena sem culpa (dolo ou culpa); proibida a responsabilidade penal **objetiva** |
| **Pessoalidade (intranscendência)** | A pena **não passa** da pessoa do condenado |
| **Individualização da pena** | Cada condenado recebe a pena adequada ao seu caso |
| **Humanidade** | Proíbe penas cruéis, de morte (salvo guerra), perpétuas, de trabalhos forçados e de banimento |
| ***Ne bis in idem*** | Ninguém é punido duas vezes pelo mesmo fato |
| **Adequação social** | Condutas aceitas socialmente não são crime (ex.: furar a orelha da criança para colocar brinco) |

## Teste-se

**1.** Uma medida provisória pode criar um crime?

<details><summary>Ver resposta</summary>

**Não**; só **lei** em sentido estrito (reserva legal).

</details>

**2.** O juiz pode usar analogia para punir um fato parecido com um crime, mas não previsto em lei?

<details><summary>Ver resposta</summary>

**Não**; é proibida a analogia *in malam partem*.

</details>

**3.** Qual princípio impede punir quem se automutila?

<details><summary>Ver resposta</summary>

**Lesividade (ofensividade)**.

</details>

**4.** O que significa dizer que o Direito Penal é a *ultima ratio*?

<details><summary>Ver resposta</summary>

Que ele deve ser o **último recurso**, usado só quando outros ramos do Direito não bastarem (intervenção mínima).

</details>
