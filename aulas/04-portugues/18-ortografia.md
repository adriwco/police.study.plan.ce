# Ortografia (emprego das letras)

> **Tempo:** 40 minutos · **Pré-requisito:** nenhum

## Por que isso importa

Erros de grafia custam 0,25 cada na redação e caem em questões de "assinale a palavra grafada corretamente".

## As confusões mais comuns

| Dúvida | Regra / dica | Exemplos |
|---|---|---|
| **-ês / -esa** (origem, título) x **-ez / -eza** (substantivos abstratos de adjetivos) | Nacionalidade/título: **s**. Qualidade: **z** | português, princesa · rapidez, beleza, certeza |
| **-isar** x **-izar** | Se a palavra de origem tem **s**, -isar; senão, -izar | análise → anali**s**ar; pesquisa → pesqui**s**ar · real → reali**z**ar; útil → utili**z**ar |
| **-ção** x **-são** | Verbos em -**ter** → -**tenção**; verbos em -**nder**/-**ndir** → -**nsão** | deter → deten**ç**ão, reter → reten**ç**ão · pretender → preten**s**ão, expandir → expan**s**ão |
| **x** x **ch** | Depois de ditongo e depois de "en" (em regra): **x** | caixa, peixe, enxame, enxada (mas encher, de "cheio") |
| **g** x **j** | -agem, -igem, -ugem: **g** · verbos em -jar mantêm j | viagem (substantivo) x que eles viajem (verbo) |
| **s** x **ss** x **ç** | Depois de consoante, som de s: **s** | pensar, ganso |

## Porquês

| Forma | Quando usar | Exemplo |
|---|---|---|
| **por que** | Pergunta; ou = "pelo qual/pela qual" | "**Por que** fugiu?" · "O motivo **por que** fugiu." |
| **por quê** | No fim da frase | "Fugiu **por quê**?" |
| **porque** | Resposta, explicação (= pois) | "Fugiu **porque** teve medo." |
| **porquê** | Substantivo (com artigo) | "Não sei **o porquê** da fuga." |

## Parônimos e homônimos

| Par | Significados |
|---|---|
| **mandado** x **mandato** | Mandado = ordem judicial (mandado de prisão) · Mandato = período de um cargo eletivo |
| **flagrante** x **fragrante** | Flagrante = evidente, no ato · Fragrante = perfumado |
| **delatar** x **dilatar** | Delatar = denunciar · Dilatar = aumentar |
| **descrição** x **discrição** | Descrição = ato de descrever · Discrição = reserva |
| **emergir** x **imergir** | Emergir = vir à tona · Imergir = afundar |
| **eminente** x **iminente** | Eminente = importante · Iminente = prestes a acontecer |
| **infligir** x **infringir** | Infligir = aplicar (pena) · Infringir = violar (lei) |
| **ratificar** x **retificar** | Ratificar = confirmar · Retificar = corrigir |
| **sessão / seção / cessão** | Sessão = reunião · Seção = divisão · Cessão = ato de ceder |
| **a fim de** x **afim** | A fim de = para · Afim = semelhante |
| **mal** x **mau** | Mal: oposto de **bem** · Mau: oposto de **bom** |

## Teste-se

**1.** "O juiz expediu o ____ de prisão." (mandado/mandato)

<details><summary>Ver resposta</summary>

**mandado** (ordem judicial).

</details>

**2.** "O agente ____ a lei." (infligiu/infringiu)

<details><summary>Ver resposta</summary>

**infringiu** (violou).

</details>

**3.** "Não sei ____ ele confessou." (porque/por que)

<details><summary>Ver resposta</summary>

**por que** (= o motivo pelo qual).

</details>

**4.** Qual está correta: "excessão" ou "exceção"?

<details><summary>Ver resposta</summary>

**exceção**.

</details>
