# Classes de palavras

> **Tempo:** 50 minutos · **Pré-requisito:** nenhum

## Por que isso importa

Toda a gramática da prova (concordância, crase, pontuação, colocação de pronomes) depende de saber **que tipo de palavra** é cada uma. "Crase antes de verbo" ou "concordância do adjetivo com o substantivo" só fazem sentido se você reconhece verbo, adjetivo e substantivo.

## Explicação do zero

As palavras são como peças com funções diferentes. São **10 classes**:

| Classe | O que faz | Exemplos |
|---|---|---|
| **Substantivo** | Dá nome a seres, coisas, ideias | policial, Fortaleza, justiça, crime |
| **Adjetivo** | Dá qualidade ao substantivo | policial **honesto**, crime **grave** |
| **Artigo** | Vem antes do substantivo, definindo-o ou não | **o**, **a**, **os**, **as** (definidos); **um**, **uma** (indefinidos) |
| **Numeral** | Indica quantidade ou ordem | **dois**, **segundo**, **metade**, **dobro** |
| **Pronome** | Substitui ou acompanha o substantivo | **ele**, **meu**, **este**, **que**, **alguém** |
| **Verbo** | Indica ação, estado ou fenômeno, e varia no tempo | **investigar**, **ser**, **chover** |
| **Advérbio** | Modifica o verbo, o adjetivo ou outro advérbio (tempo, lugar, modo…) | **ontem**, **aqui**, **rapidamente**, **muito**, **não** |
| **Preposição** | Liga duas palavras, criando relação | **a**, **de**, **em**, **para**, **com**, **por**, **sem** |
| **Conjunção** | Liga orações ou termos | **e**, **mas**, **porque**, **embora**, **quando**, **se** |
| **Interjeição** | Expressa emoção | **ai!**, **ufa!**, **socorro!** |

**Variáveis** (mudam de forma: gênero, número, pessoa, tempo): substantivo, adjetivo, artigo, numeral, pronome, verbo.
**Invariáveis:** advérbio, preposição, conjunção, interjeição.

## O truque: a classe depende do uso

A mesma palavra pode mudar de classe conforme a frase:

| Frase | Palavra | Classe |
|---|---|---|
| "O **jantar** está pronto." | jantar | substantivo (tem artigo antes) |
| "Vamos **jantar** cedo." | jantar | verbo |
| "Ele fala **alto**." | alto | advérbio (modifica o verbo "fala") |
| "Ele é **alto**." | alto | adjetivo (qualidade de "ele") |
| "**A** viatura chegou." | a | artigo |
| "Fui **a** Fortaleza." | a | preposição |
| "Entreguei-**a** ao delegado." | a | pronome (substitui "a arma", por exemplo) |

## Os pronomes (os mais cobrados)

| Tipo | Exemplos |
|---|---|
| Pessoais retos (sujeito) | eu, tu, ele/ela, nós, vós, eles/elas |
| Pessoais oblíquos (complemento) | me, te, se, o, a, lhe, nos, vos, os, as, lhes, mim, ti, si |
| De tratamento | você, Vossa Excelência, Vossa Senhoria |
| Possessivos | meu, teu, seu, nosso |
| Demonstrativos | este, esse, aquele, isto, isso, aquilo |
| Relativos | que, quem, o qual, cujo, onde |
| Indefinidos | alguém, ninguém, todo, algum, nenhum, cada |
| Interrogativos | que?, quem?, qual?, quanto? |

**Este x esse:** **este** = perto de quem fala, ou o que **vai** ser dito; **esse** = perto de quem ouve, ou o que **já** foi dito.

## As conjunções (base da coesão)

| Relação | Conjunções |
|---|---|
| Adição | e, nem, também |
| Oposição (adversativas) | mas, porém, contudo, todavia, entretanto, no entanto |
| Conclusão | logo, portanto, por isso, pois (depois do verbo) |
| Explicação | porque, pois (antes do verbo), que |
| Causa | porque, como, já que, visto que, uma vez que |
| Concessão | embora, ainda que, mesmo que, apesar de que |
| Condição | se, caso, desde que, contanto que |
| Finalidade | para que, a fim de que |
| Tempo | quando, enquanto, assim que, logo que |
| Consequência | que (após tão, tanto, tal), de modo que |
| Comparação | como, que (após mais/menos), assim como |
| Conformidade | conforme, segundo, consoante |

Você vai usar muito essa tabela na aula de coesão.

## Teste-se

**1.** Classifique as palavras em destaque: "**O** investigador **rapidamente** encontrou **a** prova."

<details><summary>Ver resposta</summary>

**O** = artigo · **rapidamente** = advérbio · **a** = artigo.

</details>

**2.** Em "Ele correu **muito**", qual a classe de "muito"?

<details><summary>Ver resposta</summary>

**Advérbio** (intensifica o verbo "correu").

</details>

**3.** Qual relação a conjunção "embora" expressa?

<details><summary>Ver resposta</summary>

**Concessão** (uma ideia contrária que não impede a outra: "Embora cansado, estudou").

</details>

**4.** Em "Vou **a** Sobral", "a" é artigo ou preposição?

<details><summary>Ver resposta</summary>

**Preposição** (liga "vou" a "Sobral"; o verbo "ir" exige a preposição "a").

</details>
