# Windows: arquivos, pastas e área de transferência

> **Tempo:** 45 minutos · **Pré-requisito:** "Hardware e software"

## Explicação do zero

O computador guarda tudo em **arquivos** (um documento, uma foto) organizados em **pastas** (diretórios), como num arquivo de aço com gavetas.

## Conceitos do edital

| Conceito | O que é |
|---|---|
| **Arquivo** | Unidade de informação com nome e **extensão** (ex.: `laudo.pdf`) |
| **Extensão** | Letras após o ponto que indicam o tipo: `.odt`, `.docx`, `.pdf`, `.jpg`, `.mp4`, `.exe`, `.zip` |
| **Pasta (diretório)** | Contêiner de arquivos e de outras pastas |
| **Caminho** | Endereço do arquivo: `C:\Usuários\Ana\Documentos\laudo.pdf` |
| **Área de trabalho** | Tela inicial, com ícones e barra de tarefas |
| **Atalho** | Ícone que **aponta** para um arquivo; apagar o atalho **não** apaga o arquivo |
| **Área de transferência** | Memória temporária do que você copiou ou recortou |
| **Lixeira** | Guarda os itens excluídos do disco local, permitindo restaurar |

## Copiar x recortar

| Ação | Atalho | Resultado |
|---|---|---|
| Copiar | Ctrl + C | O original **fica**; uma cópia vai para o destino |
| Recortar | Ctrl + X | O original **sai** e vai para o destino (mover) |
| Colar | Ctrl + V | Coloca o que está na área de transferência |

**Arrastar com o mouse:**
- Na **mesma unidade** (C: → C:): **move**.
- Para **outra unidade** (C: → pendrive): **copia**.
- Segurando **Ctrl**: copia. Segurando **Shift**: move.

## Excluir

| Ação | Resultado |
|---|---|
| **Delete** | Vai para a **Lixeira** (pode restaurar) |
| **Shift + Delete** | Exclui **permanentemente** (não passa pela Lixeira) |
| Excluir de **pendrive** ou rede | Normalmente **não** vai para a Lixeira |

## Explorador de Arquivos

- Abre com **Windows + E**.
- Modos de exibição: ícones, lista, detalhes (mostra tamanho, tipo, data).
- **Nomes de arquivo não podem ter:** `\ / : * ? " < > |`

</details>

**2.** Qual atalho exclui um arquivo sem enviá-lo para a Lixeira?

<details><summary>Ver resposta</summary>

**Shift + Delete**.

</details>

**3.** Apagar um atalho da área de trabalho apaga o programa?

<details><summary>Ver resposta</summary>

**Não**; só remove o atalho.

</details>
