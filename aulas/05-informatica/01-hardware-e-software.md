# Hardware e software

> **Tempo:** 35 minutos · **Pré-requisito:** nenhum

## Explicação do zero

- **Hardware** = a parte **física**, que se pode tocar: teclado, monitor, memória, processador.
- **Software** = a parte **lógica**, os programas: Windows, Linux, navegador, LibreOffice.

Comparação: o hardware é o **corpo**; o software são as **ideias e instruções** que fazem o corpo agir.

## As peças principais

| Peça | Função | Comparação |
|---|---|---|
| **CPU (processador)** | Executa as instruções; o "cérebro" | O investigador que faz o trabalho |
| **Memória RAM** | Guarda **temporariamente** o que está em uso; **apaga ao desligar** (volátil) | A mesa de trabalho |
| **Armazenamento (HD / SSD)** | Guarda **permanentemente** arquivos e programas | O arquivo da delegacia |
| **Memória ROM** | Guarda instruções de fábrica para ligar o computador (BIOS/UEFI); não volátil | O manual que vem com o aparelho |
| **Placa-mãe** | Liga todas as peças | O prédio da delegacia |
| **Fonte** | Fornece energia | — |
| **Placa de vídeo (GPU)** | Processa imagens | — |

**HD x SSD:** o HD tem disco que gira (mais lento, mais barato); o SSD não tem partes móveis (muito mais rápido).

## Periféricos

| Tipo | Exemplos |
|---|---|
| **Entrada** (enviam dados ao computador) | teclado, mouse, scanner, microfone, webcam |
| **Saída** (recebem dados do computador) | monitor, impressora, caixa de som |
| **Entrada e saída** (os dois) | monitor touchscreen, impressora multifuncional, pendrive, HD externo |

## Tipos de software

| Tipo | O que é | Exemplos |
|---|---|---|
| **Sistema operacional** | Gerencia o hardware e permite usar os outros programas | Windows, Linux, Android |
| **Aplicativo** | Programa para uma tarefa do usuário | LibreOffice, Chrome |
| **Utilitário** | Manutenção e segurança | antivírus, compactador |
| **Firmware** | Software gravado no hardware | BIOS/UEFI |

**Licenças:**
- **Software livre:** pode ser usado, estudado, modificado e distribuído (Linux, LibreOffice, Firefox).
- **Proprietário:** o código é fechado; uso conforme licença (Windows, Microsoft Office).
- **Freeware:** gratuito, mas não necessariamente livre.

## Unidades de medida

| Unidade | Tamanho |
|---|---|

| KB | 1.024 bytes |
