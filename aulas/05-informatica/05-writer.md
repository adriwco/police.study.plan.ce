# LibreOffice Writer (editor de texto)

> **Tempo:** 50 minutos + prática · **Pré-requisito:** "Atalhos de teclado"

## Explicação do zero

O **Writer** é o editor de texto do LibreOffice (equivalente ao Word). Formato padrão: **`.odt`** (OpenDocument Text). Também abre e salva `.docx` e exporta `.pdf`.

**Pratique:** abra o Writer e repita cada item desta aula.

## O que o edital cobra

| Recurso | Onde fica | O que faz |
|---|---|---|
| **Formatação de caractere** | Formatar → Caractere | Fonte, tamanho, negrito, itálico, cor |
| **Formatação de parágrafo** | Formatar → Parágrafo | Alinhamento, recuos, espaçamento entre linhas |
| **Estilos** | F11 (painel Estilos) | Formatação pronta (Título 1, Corpo de texto); base dos índices |
| **Marcadores e numeração** | Formatar → Marcadores e numeração | Listas com símbolos (•) ou números (1, 2, 3) |
| **Colunas** | Formatar → Colunas | Texto em colunas, como jornal |
| **Cabeçalho e rodapé** | Inserir → Cabeçalho e rodapé | Área repetida no topo/base de todas as páginas |
| **Número de página** | Inserir → Número da página (ou Campo) | Numeração automática |
| **Quebra de página** | Inserir → Mais quebras / Ctrl + Enter | Força o texto a começar na página seguinte |
| **Tabela** | Tabela → Inserir tabela (Ctrl + F12) | Linhas e colunas |
| **Índice (sumário)** | Inserir → Sumário e índice | Gerado a partir dos **estilos de título** |
| **Legenda** | Inserir → Legenda | "Figura 1: …" abaixo de imagens/tabelas |
| **Campos** | Inserir → Campo | Data, hora, número de páginas, autor — atualizados sozinhos |
| **Caixa de texto** | Inserir → Caixa de texto | Texto em área móvel |
| **Imprimir** | Arquivo → Imprimir (Ctrl + P) | Escolher páginas, cópias |
| **Exportar como PDF** | Arquivo → Exportar como PDF | Gera PDF |
| **Controlar alterações** | Editar → Controlar alterações | Registra o que cada um mudou (revisão) |

## Seleção com o mouse

| Ação | Seleciona |
|---|---|
| 2 cliques | Uma palavra |
| 3 cliques | Uma frase |
| 4 cliques | O parágrafo |

## Diferenças de nome em relação ao Word (caem!)

| Word | Writer |
|---|---|
| `.docx` | `.odt` |
| Página Inicial (guia) | Menus **Formatar**, **Inserir** |
| Revisão → Controlar Alterações | **Editar** → Controlar alterações |
| Sumário | Sumário e índice |
