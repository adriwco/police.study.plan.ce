# Atalhos de teclado

> **Tempo:** 30 minutos + uso diário por uma semana · **Pré-requisito:** "Windows"

## Como estudar

Não decore de uma vez. **Use** estes atalhos no seu computador por uma semana. Depois, faça flashcards só dos que não fixaram.

## Universais (funcionam em quase todo programa)

| Atalho | Ação |
|---|---|
| Ctrl + C | Copiar |
| Ctrl + X | Recortar |
| Ctrl + V | Colar |
| Ctrl + Z | Desfazer |
| Ctrl + Y | Refazer |
| Ctrl + A | Selecionar tudo |
| Ctrl + S | Salvar |
| Ctrl + P | Imprimir |
| Ctrl + F | Localizar |
| Ctrl + N | Novo documento/janela |
| Ctrl + O | Abrir |
| Ctrl + W | Fechar a janela/aba atual |
| F1 | Ajuda |

## Windows

| Atalho | Ação |
|---|---|
| **Windows** | Abre o menu Iniciar |
| **Windows + E** | Explorador de Arquivos |
| **Windows + D** | Mostra a área de trabalho |
| **Windows + L** | **Bloqueia** o computador |
| **Windows + R** | Executar |
| **Windows + I** | Configurações |
| **Windows + V** | Histórico da área de transferência |
| **Windows + Shift + S** | Captura de parte da tela |
| **Alt + Tab** | Alterna entre janelas |
| **Alt + F4** | Fecha o programa |
| **Ctrl + Shift + Esc** | Gerenciador de Tarefas |
| **F2** | Renomear o item selecionado |
| **F5** | Atualizar |
| **Shift + Delete** | Excluir permanentemente |

## Navegadores (Chrome e Firefox)

| Atalho | Ação |
|---|---|
| Ctrl + T | Nova aba |
| Ctrl + Shift + T | Reabre a última aba fechada |
| Ctrl + Shift + N (Chrome) / Ctrl + Shift + P (Firefox) | Janela anônima/privativa |
| Ctrl + H | Histórico |
| Ctrl + J | Downloads |
| Ctrl + D | Adicionar aos favoritos |
| Ctrl + Tab | Próxima aba |
| F5 | Recarregar |
| Ctrl + L | Selecionar a barra de endereço |

## Writer (LibreOffice)

| Atalho | Ação |
|---|---|
| Ctrl + B | **Negrito** |
| Ctrl + I | *Itálico* |
| Ctrl + U | Sublinhado |
| Ctrl + E | Centralizar |
| Ctrl + L | Alinhar à esquerda |
| Ctrl + R | Alinhar à direita |
| Ctrl + J | Justificar |
| Ctrl + Enter | Quebra de página |
| Ctrl + H | Localizar e substituir |
| F7 | Ortografia |

> Atalhos podem variar com a versão e o idioma do programa. Confira no seu LibreOffice (menu **Ferramentas → Personalizar → Teclado**).
