# Navegadores (Chrome e Firefox)

> **Tempo:** 35 minutos · **Pré-requisito:** "Atalhos de teclado"

## Explicação do zero

O **navegador** é o programa que abre páginas da internet. O edital cita **Google Chrome** e **Mozilla Firefox**.

## Recursos cobrados

| Recurso | O que é |
|---|---|
| **URL** | Endereço da página: `https://www.policiacivil.ce.gov.br/concursos` |
| **Link (hiperlink)** | Texto ou imagem que leva a outra página |
| **Aba** | Várias páginas na mesma janela |
| **Favoritos** | Páginas salvas para acesso rápido (Ctrl + D) |
| **Histórico** | Lista de páginas visitadas (Ctrl + H) |
| **Downloads** | Arquivos baixados (Ctrl + J) |
| **Cache** | Cópias de partes das páginas guardadas para carregar mais rápido |
| **Cookies** | Pequenos arquivos que os sites gravam para lembrar você (login, preferências) |
| **Navegação anônima/privativa** | Não guarda histórico, cookies e dados de formulário **no computador** depois de fechada |
| **Extensões** | Pequenos programas que acrescentam funções ao navegador |
| **Imprimir página** | Ctrl + P (inclui "Salvar como PDF") |
| **Localizar na página** | Ctrl + F |

## Navegação anônima NÃO torna você invisível

Ela **não** esconde sua navegação do provedor de internet, da empresa/rede onde você está nem dos sites visitados. Ela só evita que os dados fiquem **gravados no seu computador**. Downloads e favoritos criados na janela anônima **permanecem**.

## Partes de uma URL

```
https://www.cev.uece.br/oippcce/edital.pdf
└─┬─┘   └──────┬──────┘└────────┬────────┘
protocolo   domínio          caminho
```

- **http** = sem criptografia · **https** = com criptografia (cadeado).
- **.gov.br** = governo · **.jus.br** = Judiciário · **.edu.br** = educação · **.org** = organizações.

## Busca eficiente (operadores do Google)

| Operador | Efeito | Exemplo |
|---|---|---|
| `"..."` | Frase exata | `"oficial investigador"` |
| `-` | Exclui termo | `concurso polícia -militar` |
| `site:` | Busca num site | `edital site:cev.uece.br` |
| `filetype:` | Tipo de arquivo | `estatuto polícia civil ceará filetype:pdf` |
| `OR` | Um ou outro | `PCCE OR "polícia civil ceará"` |
