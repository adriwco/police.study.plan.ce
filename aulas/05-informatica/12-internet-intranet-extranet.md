# Internet, intranet e extranet; redes

> **Tempo:** 40 minutos · **Pré-requisito:** "Navegadores"

## Explicação do zero

Uma **rede** é um conjunto de computadores ligados para trocar informações.

| Rede | O que é | Acesso |
|---|---|---|
| **Internet** | Rede mundial, pública | Qualquer pessoa |
| **Intranet** | Rede **privada** de uma organização, que usa as **mesmas tecnologias** da internet (navegador, HTTP) | Só funcionários (ex.: sistema interno da Polícia Civil) |
| **Extranet** | Parte da intranet aberta a **parceiros externos autorizados** | Funcionários + parceiros (ex.: um fornecedor, outro órgão) |

**Intranet não exige estar fisicamente no prédio**: pode ser acessada de fora por **VPN** (rede privada virtual, um "túnel" criptografado).

## Tipos de rede por tamanho

| Sigla | Alcance | Exemplo |
|---|---|---|
| **PAN** | Pessoal (poucos metros) | Bluetooth do celular com o fone |
| **LAN** | Local (prédio) | Rede da delegacia |
| **MAN** | Metropolitana (cidade) | Rede entre unidades de Fortaleza |
| **WAN** | Longa distância (países) | A internet |

## Protocolos que caem

| Protocolo | Função |
|---|---|
| **TCP/IP** | Conjunto de regras básico da internet |
| **IP** | Endereçamento: cada dispositivo tem um número (IPv4: `192.168.0.1`; IPv6 é mais longo) |
| **HTTP / HTTPS** | Páginas web (HTTPS com criptografia) |
| **DNS** | Traduz nomes (`google.com`) em endereços IP — a "lista telefônica" da internet |
| **FTP** | Transferência de arquivos |
| **SMTP / POP3 / IMAP** | E-mail (envio / recebimento) |
| **DHCP** | Distribui endereços IP automaticamente na rede |

## Equipamentos

| Equipamento | Função |
|---|---|
| **Modem** | Conecta à operadora de internet |
| **Roteador** | Distribui a conexão e direciona os dados entre redes (muitas vezes com Wi-Fi) |
| **Switch** | Liga computadores dentro da rede local |
| **Ponto de acesso (access point)** | Fornece Wi-Fi |
