# LibreOffice Impress (apresentações)

> **Tempo:** 30 minutos · **Pré-requisito:** "Writer"

## Explicação do zero

O **Impress** cria apresentações de slides (equivalente ao PowerPoint). Formato padrão: **`.odp`**.

## O que o edital cobra

| Recurso | O que é |
|---|---|
| **Slide** | Cada "página" da apresentação |
| **Layout** | Disposição dos espaços (título, conteúdo, duas colunas) |
| **Slide mestre** | Modelo que define a aparência de todos os slides (fundo, fontes, logotipo) |
| **Anotações** | Texto para o apresentador, que o público não vê |
| **Régua e guias** | Ajudam a alinhar objetos |
| **Cabeçalho e rodapé** | Data, número do slide, texto fixo |
| **Animação** | Efeito em um **objeto** dentro do slide (um texto que surge) |
| **Transição** | Efeito na **passagem** de um slide para outro |
| **Botões de ação / interação** | Objeto que, ao ser clicado, leva a outro slide ou abre algo |

**Animação x transição (cai!):** animação = objeto; transição = troca de slide.

## Modos de exibição

| Modo | Para quê |
|---|---|
| Normal | Editar slides |
| Estrutura de tópicos | Ver só os textos |
| Notas | Editar as anotações |
| Classificador de slides | Ver miniaturas e reordenar |

## Atalhos

| Atalho | Ação |
|---|---|
| **F5** | Iniciar apresentação do **primeiro** slide |
| **Shift + F5** | Iniciar do slide **atual** |
| **Esc** | Encerrar a apresentação |

## Teste-se

**1.** Qual a diferença entre animação e transição?

<details><summary>Ver resposta</summary>

</details>
