# Calc: gráficos, classificação e dados

> **Tempo:** 35 minutos + prática · **Pré-requisito:** "Calc: fórmulas e funções"

## Gráficos

**Inserir → Gráfico**, depois de selecionar os dados.

| Tipo | Melhor para |
|---|---|
| **Colunas / barras** | Comparar quantidades entre categorias |
| **Linhas** | Mostrar evolução no tempo |
| **Pizza** | Partes de um todo (percentuais) |
| **Dispersão (XY)** | Relação entre duas variáveis |

## Classificar e filtrar

| Recurso | Onde | O que faz |
|---|---|---|
| **Classificar** | Dados → Classificar | Ordena (crescente/decrescente) por uma ou mais colunas |
| **AutoFiltro** | Dados → AutoFiltro | Setas nos cabeçalhos para mostrar só o que interessa |
| **Filtro avançado / padrão** | Dados → Mais filtros | Critérios combinados |

**Filtrar não apaga dados:** só esconde as linhas que não atendem ao critério.

## Outros recursos do edital

| Recurso | Onde | Para quê |
|---|---|---|
| **Formatação condicional** | Formatar → Condicional | Muda a cor da célula conforme o valor (ex.: vermelho abaixo de 50%) |
| **Validação de dados** | Dados → Validade | Restringe o que pode ser digitado (só números, lista) |
| **Obter dados externos** | Planilha → Vincular a dados externos | Importa dados de outro arquivo ou da web |
| **Macros** | Ferramentas → Macros | Grava e repete sequências de ações (automatização) |
| **Congelar linhas/colunas** | Exibir → Congelar células | Mantém o cabeçalho visível ao rolar |
| **Quebras e numeração de página** | Inserir → Quebra de página; Formatar → Página | Controle da impressão |
| **Alça de preenchimento** | Quadradinho no canto da célula | Arrastar para copiar ou continuar sequências (1, 2, 3… / jan, fev…) |
